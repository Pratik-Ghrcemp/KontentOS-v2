# KontentOS Source of Truth

**Official Workspace**: `New folder (4)/KontentOS`

This directory contains the modernized **Next.js + React + TypeScript + Supabase** version of KontentOS. It is the official active workspace for all future development.

**Legacy Preservation**:
The older Vite/Vanilla JS version of the project is preserved under the `legacy/` folder (and in the old project directory `Project/KontentOS` as a backup source). These older files should only be treated as a reference or backup, especially for deeper Raw Studio UI/logic and past mockups.

**Design & UI Context**:
The "Raw-to-Reel" reference image and the old V2 Figma designs serve purely as visual inspiration and quality benchmarks. They do not dictate the final mandatory design. The primary focus remains on **premium creator-tool feeling**, solid Next.js component architecture, and functional stability over pixel-perfect adherence to old screenshots.

**Product Strategy**:
- Complete functionality (Phase 0 stabilization, backend wiring, and core workflows) has a higher priority than purely visual/aesthetic redesigns.
- Product documentation remains the single source of truth for features and behavior requirements.
